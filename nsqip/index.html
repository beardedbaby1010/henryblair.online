NSQIP research kit

Sets up a Mac to build ACS NSQIP research projects (cohorts, workbooks, figures).

curl -fsSL https://henryblair.online/nsqip/install.sh | zsh

Paste into Terminal on a Mac and press return.

What it does

Downloads the kit into ~/Documents/NSQIP, installs what it needs, then starts the setup. It is safe to run again — it never touches existing projects or data.

Prefer not to paste commands?

Download the zip instead →

The NSQIP data files aren’t included. You need your own access through the ACS NSQIP Participant Use Data File program.
