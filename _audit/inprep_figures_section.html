Regenerate figures from the live sheet

Every figure generator already takes its workbook from an environment variable (ADI_XLSX, PVR_XLSX, VE_XLSX, URPS_XLSX) and its output directory from a matching *_FIGDIR. So none of them has to be rewritten to read live data: download the Google Sheet as .xlsx, point the variable at the download, run the script untouched. The export carries the computed values alongside the formulas, which is why data_only=True still sees real numbers.

regen_figures.py in the site repo does exactly that, and nothing else. It reports which figures it wrote and which it overwrote, deletes the download afterwards, and never touches a figure a script did not produce.
