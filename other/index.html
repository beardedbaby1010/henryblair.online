Research tooling · ACS NSQIP Participant Use Files

A pipeline that turns the NSQIP files into a finished analysis

Henry M. Blair

The ACS NSQIP public files are thirteen years of fixed-width text whose columns appear, vanish and change name between years. This is the toolchain I wrote to go from no research question at all to a cohort, a live workbook, publication figures and a written guide — about eight thousand lines of Python, run by double-clicking one file.

Research tooling · TriNetX US Collaborative Network

A command line for the TriNetX query browser

Henry M. Blair

TriNetX is a browser. Every count is a card you click, every definition is a panel you expand, and a study with eighty queries becomes eighty sessions of clicking that nobody can reproduce. This drives that interface from the command line instead — refreshing counts, dumping each query’s full definition to text, and renaming in bulk — so a cohort can be rebuilt by running a line rather than remembered.
